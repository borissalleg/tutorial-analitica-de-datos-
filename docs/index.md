## 2. Justificación

El contexto empresarial trae consigo una nueva realidad que permite integrar a las organizaciones algunos factores importantes como la **toma de decisiones basadas en altos volúmenes de datos**. 

Es por esto que con el curso **Análisis de Datos**, se pretende proporcionar a los estudiantes una comprensión sólida de los conceptos fundamentales y de las diferentes tecnologías y técnicas utilizadas en el campo del **Big Data**; de manera que los estudiantes puedan manejar diferentes herramientas y tecnologías para el procesamiento de datos.

---

## 3. Resultados de Aprendizaje

Al finalizar el curso, el estudiante estará capacitado para:

1.  **Identificar** las etapas del proceso de análisis de datos, las fuentes y tipos de datos, y los métodos adecuados para su análisis.
2.  **Procesar** conjuntos de datos, aplicando técnicas de limpieza, transformación y visualización.
3.  **Utilizar** herramientas para importar, transformar y modelar datos de manera eficiente.
4.  **Integrar** datos de diversas fuentes utilizando Power BI, empleando técnicas de limpieza, transformación y modelado para asegurar su calidad y consistencia.

## 4. Unidades Temáticas y Cronograma Semanal

### Unidad 01: Conceptos fundamentales del análisis de datos
> **Resultado de aprendizaje:** Identifica las etapas del proceso de análisis de datos, las fuentes y tipos de datos, y los métodos adecuados para su análisis.

| Semana | Contenido de Enseñanza |
| :---: | :--- |
| **1** | • Concepto y etapas del análisis de datos<br>• Relación del análisis de datos con la estadística, la econometría y el Machine Learning |
| **2** | • Casos de aplicación del análisis de datos en la administración de negocios<br>• Fuentes de datos |
| **3** | • Concepto de base de datos<br>• Clases de bases de datos: Relacionales y no relacionales<br>• Tipos de datos: Corte transversal, serie de tiempo, datos longitudinales |
| **4** | • Calidad de los datos: completitud, consistencia y precisión<br>• Escala de medición de las variables |

---

### Unidad 02: Preparación y análisis de Datos en RStudio o Python
> **Resultado de aprendizaje:** Procesa conjuntos de datos, aplicando técnicas de limpieza, transformación y visualización.

| Semana | Contenido de Enseñanza |
| :---: | :--- |
| **5** | • Selección y cargue de la base de datos<br>• Estructura de los datos y manipulación de variables |
| **6** | • Técnicas de selección y filtrado de datos<br>• Técnicas de limpieza de datos: Identificación y tratamiento de valores nulos, duplicados y atípicos |
| **7 y 8** | • **Análisis exploratorio de datos (EDA):**<br>  - Transformación de datos<br>  - Técnicas de análisis descriptivo<br>  - Visualización de datos básicos |

---

### Unidad 03: Introducción a Power Query y Power Pivot
> **Resultado de aprendizaje:** Utilizar herramientas para importar, transformar y modelar datos de manera eficiente.

| Semana | Contenido de Enseñanza |
| :---: | :--- |
| **9** | • Importar datos desde diferentes fuentes<br>• Limpieza y transformación de los datos |
| **10** | • Conexión de datos desde múltiples fuentes<br>• Automatización de consultas |
| **11** | • Identificación de relaciones entre tablas<br>• Cálculos avanzados a través de la fórmula DAX |
| **12** | • Cálculos avanzados a través de la fórmula DAX (Continuación y práctica) |

---

### Unidad 04: Integración de Datos y Preparación en Power BI
> **Resultado de aprendizaje:** Integra datos de diversas fuentes utilizando Power BI, empleando técnicas de limpieza, transformación y modelado para asegurar su calidad y consistencia.

| Semana | Contenido de Enseñanza |
| :---: | :--- |
| **13 y 14** | • Introducción a Power BI y su entorno de desarrollo<br>• Conexión a diversas fuentes de datos<br>• Proceso de limpieza y preparación de datos en Power BI (valores nulos, duplicados, transformaciones)<br>• Diseño y desarrollo de paneles de control y dashboards |
| **15** | • Otras herramientas de visualización: Tableau y Looker Studio<br>• Desarrollo de visualizaciones para comunicar hallazgos |
| **16** | • Selección de las técnicas de visualización según los resultados y el contexto del problema |
